Página de Ejemplo

Esta es una página de ejemplo que demuestra cómo usar los componentes reutilizables de navbar y footer.

Como puedes ver, el navbar y el footer se cargan automáticamente sin necesidad de copiar y pegar todo el código HTML.

Ventajas de este sistema:

  • ✓ Solo necesitas incluir un div con id="navbar-container" y otro con id="footer-container"
  • ✓ El JavaScript carga automáticamente los componentes
  • ✓ La funcionalidad del menú móvil se inicializa automáticamente
  • ✓ Si necesitas actualizar el navbar o footer, solo lo haces en un lugar
  • ✓ Código más limpio y mantenible

💡 Nota para Desarrolladores

Para crear una nueva página, simplemente copia este archivo HTML y modifica solo la sección <main> con tu contenido. El navbar y footer se cargarán automáticamente.
